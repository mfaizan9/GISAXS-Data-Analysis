Three coordinate systems

systemaxesmeaning
lab frame\(X, Y, Z\)\(X\) along the incident beam, \(Z\) vertical up, \(Y = Z \times X\) (horizontal)
sample frame\(\hat{\mathbf u}, \hat{\mathbf v}, \hat{\mathbf n}\)\(\hat{\mathbf u}\) in the surface along the beam, \(\hat{\mathbf v} = \hat{\mathbf Y}\) in the surface, \(\hat{\mathbf n}\) the surface normal
detector\(x, y\)position on the detector in mm, measured from the direct beam; the detector plane is the \(Y\)–\(Z\) plane: \(x\) along \(Y\), \(y\) along \(Z\) (up)

The sample is tilted by \(\alpha_i\) about \(Y\). In lab components

$$\hat{\mathbf u}=(\cos\alpha_i,\ 0,\ \sin\alpha_i),\qquad \hat{\mathbf v}=(0,\ 1,\ 0),\qquad \hat{\mathbf n}=(-\sin\alpha_i,\ 0,\ \cos\alpha_i)$$

All results \((\varphi_f,\ \alpha_f,\ \mathbf k_f,\ \mathbf q)\) are in the sample frame: the components written \(x, y, z\) \((k_{fx},\ q_x,\ \dots)\) are the components along \(\hat{\mathbf u}, \hat{\mathbf v}, \hat{\mathbf n}\).

From a pixel to \(\mathbf q\)

Pixel position

The vector from the sample to the pixel, in the lab frame and in the sample frame:

$$\mathbf r = L\,\hat{\mathbf X} + x\,\hat{\mathbf Y} + y\,\hat{\mathbf Z} = a\,\hat{\mathbf u} + b\,\hat{\mathbf v} + c\,\hat{\mathbf n}$$ $$a = L\cos\alpha_i + y\sin\alpha_i,\qquad b = x,\qquad c = y\cos\alpha_i - L\sin\alpha_i$$ $$R = \sqrt{L^2 + x^2 + y^2} = \sqrt{a^2+b^2+c^2}$$

Exit angles

$$\varphi_f = \operatorname{atan2}(b,\ a),\qquad \alpha_f = \operatorname{atan2}\!\left(c,\ \sqrt{a^2+b^2}\right)$$

\(\varphi_f\) increases with \(x\).

Wavevectors

$$k = \frac{2\pi}{\lambda},\qquad \mathbf k_f = \frac{k}{R}\,(a,\ b,\ c),\qquad \mathbf k_i = k\,(\cos\alpha_i,\ 0,\ -\sin\alpha_i)$$ $$k_{fx} = k\,\frac{a}{R} = k\cos\alpha_f\cos\varphi_f,\qquad k_{fy} = k\,\frac{b}{R} = k\cos\alpha_f\sin\varphi_f,\qquad k_{fz} = k\,\frac{c}{R} = k\sin\alpha_f$$

Scattering vector \(\mathbf q = \mathbf k_f - \mathbf k_i\)

$$q_x = k\left(\frac{a}{R} - \cos\alpha_i\right),\qquad q_y = k\,\frac{b}{R},\qquad q_z = k\left(\frac{c}{R} + \sin\alpha_i\right)$$

Equivalently

$$q_x = k(\cos\alpha_f\cos\varphi_f - \cos\alpha_i),\qquad q_y = k\cos\alpha_f\sin\varphi_f,\qquad q_z = k(\sin\alpha_f + \sin\alpha_i)$$

The code uses the \(a/R,\ b/R,\ c/R\) form, vectorised over all pixels.

Special positions

featureconditiondetector position
direct beam\(\alpha_f = -\alpha_i,\ \varphi_f = 0\)\(x = 0,\ y = 0\)

specular spot\(\alpha_f = \alpha_i,\ \varphi_f = 0\)\(x = 0,\ y = L\tan 2\alpha_i\)

Horizon cut

For each detector row, at \(x = 0\),

$$\alpha_{f,\text{row}} = \operatorname{atan2}(c,\ a)$$

and every row with \(\alpha_{f,\text{row}} < 0\) is dropped as a whole, so the data stays a rectangular image. The beamstop lies below the horizon and goes with it.

Conventions and assumptions

  • The detector is perpendicular to the incident beam at distance \(L = |\mathbf N|\); only the length of the .pro normal vector \(\mathbf N\) is used.
  • \(x, y\) are measured from the detector origin given in the .dat file, taken to be the direct beam.
  • \(\varphi_f\) increases with \(x\). BornAgain uses the opposite sign for \(\varphi_f\) and \(q_y\); this app does not.
  • Angles are shown and exported in degrees, and the trigonometry is done in radians. \(k\) and \(q\) are in \(\mathrm{nm}^{-1}\) (\(\lambda\) is in nm), or in \(\text{Å}^{-1}\) with the toggle in the converter.
